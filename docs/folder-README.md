# Documentation

This folder contains all project documentation and style guides.

## Files

- **README.md** (126 lines) - Main project documentation
  - Project overview and features
  - Setup and installation instructions
  - Usage guide and API details

- **style-guide.md** (316 lines) - Design system documentation
  - Typography scale and font choices
  - Color palette (muted grays, no bright colors)
  - Component patterns and layout principles
  - Extracted from The Residency website design patterns

## Purpose

The documentation in this folder helps maintain design consistency and provides onboarding guidance for developers working on the Weekly Update Dashboard. The style guide ensures all UI elements follow the established muted, professional aesthetic inspired by The Residency's design language.
